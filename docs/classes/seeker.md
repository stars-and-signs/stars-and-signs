## Core Class Features

When you gain this Class, you gain the Archivist and Quick-witted Class Features.

### Archivist

You have a five-slot Progress Counter called "Case File". Whenever you score a Hit or better on a Discover Check, once you learn the result, you can choose to dedicate your Case File to the subject of that Check. If you do, fill a slot. Whenever you succeed on a Discover Check or Remember Test related to the subject of your Case File, fill a slot.

When you fill the last slot of your Case File Counter, clear it and gain a Temporary Positive Trait representing that subject. If you start a new Case File before finishing one, clear all filled Case File slots.

When you make a Remember Test related to a subject for which you have a Case File Trait, you can invoke that Trait to automatically succeed on that Test.

You lose all Case File Traits and clear all filled Case File slots at Major Milestones.

### Quick-witted

When you take the Discover or Utilize Action, you can spend 5 Sweat. If you do, you can take that Action without suffering a Complication.
